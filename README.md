# Linear versus Chaos Feature Analysis
Repository containing the python analysis files for statistical analysis of Linear and Chaos feature analysis for finger motor imagery. 

The dataset is available at: https://doi.org/10.18112/openneuro.ds008446.v1.0.1

## Usage

The .csv files provided in the sourcedata directory can be loaded and processed via calling LvCLibMain. Here the user has to input whether they want to run formal feature extraction (FE) or initialise statistical analysis (ST). 

The Statistical Analysis call can also be executed within each of the three analysis scripts, without the need to initialise the main library.
